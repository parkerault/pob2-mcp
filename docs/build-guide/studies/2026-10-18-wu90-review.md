# WU-90 review sheet: the pattern library's new entries (2026-10-18)

Amendment 8 adds entries to the pattern library (`.claude/skills/build-guide/references/patterns.md`): the
standard kits that make sure the obvious build is always in the deck (D-403), and the library's other new entries
(D-409). They bind only once you have reviewed them; the library marks them "Awaiting review". Each row below is one
claim and its source. Mark a row OK, or correct it.

**Sources.** A *study* is an agent's report on a creator's guide or video, under `docs/build-guide/studies/`: it
shows what players do, not game truth; its patch follows its first mention. *pin:* is a grep of the pinned PoB
data (v0.23.1, game 0.5.4) under `vendor/PathOfBuilding-PoE2/src/`, run on 2026-10-18; it says what the game
allows, not what players use ("lookup" stays the lookup tool's word). *The user* is cited only where amendment 8
(`docs/build-guide/spec/amendment-8-engine-lens.md`) quotes you. "The comparison" is
`studies/2026-10-17-varashta-comparison.md` (Navira's 0.5.5 guide against our run on the 0.5.4 pin).

## Check these first

1. **Questions 11–14 have their own section**, "Brainstorm questions 11–14: the engine", right after the first
   ten. The existing static test counts exactly ten questions in the first section, and that test file belongs to
   WU-91 (the skill-text unit).
2. **"Filler to satisfy a count" gained one sentence.** The amendment asks it to stay as it is and to point to the
   new "A count as a multiplier"; its five fields are word for word as before, and its Cautions end with "When the
   count multiplies damage, see A count as a multiplier."
3. **Three kits are thin.** Crossbows and spears rest on off-meta studies only, and totems on one study plus
   the pinned data. None of the three shows what an average player knows; each says "thin" in the library.
4. **The minion kit's focus.** The amendment and the Varashta comparison put minion levels on the focus. In the pin,
   a focus rolls them only from the abyssal "of Amanamu" suffix (+1–2), not from a regular affix.
5. **Left out for want of a source:** named minion damage supports (the studies name them only as a build's
   choices); a spectre kit; shields and one-hand maces with block; talismans and shapeshifting; ballista totems
   (the pin has a "+2 Ballista Totems" mod, but no study uses one); a poison kit (our only poison study is Path of
   Exile 1); elemental penetration as a standard support; casters on Chaos Inoculation.
